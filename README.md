# AtherOS
A command-line simulator written in C++ for Windows.

> 这是一个自研控制台模拟系统，支持命令解析、密码管理等功能。

## Environment
- OS: Windows 10 / Windows 11
- Compiler: MSYS2 GCC / MinGW GCC
- C++ Standard: C++17
- Dependency: nlohmann/json

## Build

```bash
g++ -g AtherOS_1.cpp -o AtherOS_1.exe
```
